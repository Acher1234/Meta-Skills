# Origin

Elasticsearch REST API — cluster info, health, and index listing.

- Python client: [elasticsearch-py](https://www.elastic.co/guide/en/elasticsearch/client/python-api/current/index.html)
- REST: [Elasticsearch APIs](https://www.elastic.co/docs/api/doc/elasticsearch)
- Auth: HTTP basic (`USERNAME` / `PASSWORD`) against `URL`

Base URL: `$URL` (example `https://localhost:9200`)
