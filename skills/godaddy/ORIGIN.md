# Origin

GoDaddy Domains API **v3** — Discovery + DNS records.

- Discovery: [domains/v3/discovery](https://developer.godaddy.com/en/docs/references/rest/domains/v3/discovery)
- Domains list (v1): [domains/v1/manage-domain-settings](https://developer.godaddy.com/en/docs/references/rest/domains/v1/manage-domain-settings) — `GET /v1/domains`
- Domains get (v3): [domains/v3/domains](https://developer.godaddy.com/en/docs/references/rest/domains/v3/domains)
- DNS records: [domains/v3/records](https://developer.godaddy.com/en/docs/references/rest/domains/v3/records)
- Auth (PAT Bearer): [api-users/auth](https://developer.godaddy.com/en/docs/api-users/auth)

Base URL: `https://api.godaddy.com`  
Auth header: `Authorization: Bearer ${GODADDY_PAT}`
