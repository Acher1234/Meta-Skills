# youtrack-projects — Commands

Requires `skill_env.py` + `yt auth login`. Confirm before create / configure.
All commands support `--help` for full options.

| Command | Description |
|---------|-------------|
| `yt projects list [--show-archived]` | List projects |
| `yt projects create "Name" "KEY" [--leader USER] [--template scrum]` | Create project |
| `yt projects configure KEY [--description …]` | Update project settings |
| `yt users list` | List users |
