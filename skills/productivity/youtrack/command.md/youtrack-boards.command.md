# youtrack-boards — Commands

Requires `skill_env.py` + `yt auth login`.
All commands support `--help` for full options.

| Command | Description |
|---------|-------------|
| `yt boards list` | List agile boards |
| `yt burndown PROJECT-ID [--sprint "Sprint 1"]` | Burndown report |
| `yt velocity PROJECT-ID [--sprints N]` | Velocity report |
| `yt reports burndown PROJECT-ID [--sprint "Sprint 1"]` | Nested burndown |
| `yt reports velocity PROJECT-ID [--sprints N]` | Nested velocity |
