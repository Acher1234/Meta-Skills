# youtrack-articles — Commands

Requires `skill_env.py` + `yt auth login`. Confirm before create / update / delete.
All commands support `--help` for full options.

| Command | Description |
|---------|-------------|
| `yt articles search "authentication"` | Search knowledge base |
| `yt articles tree --project-id ID` | Article tree for a project |
| `yt articles create "Title" [--content …] [--file path] [--project-id ID]` | Create article |
| `yt articles tag ARTICLE-ID TAG [TAG…]` | Tag articles |
