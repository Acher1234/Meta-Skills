# jira-fields — Commands

All commands support `--help` for full options.

| Command | Description |
|---------|-------------|
| `jira-as fields list` | List all custom fields in the instance |
| `jira-as fields check-project` | Check field availability for a project |
| `jira-as fields configure-agile` | Configure Agile fields (company-managed) |
| `jira-as fields create` | Create a new custom field (admin) |
