# jira-bulk — Commands

All commands support `--help` for full options.

| Command | Description |
|---------|-------------|
| `jira-as bulk transition` | Move issues to new status |
| `jira-as bulk assign` | Assign issues to user |
| `jira-as bulk set-priority` | Set issue priority |
| `jira-as bulk clone` | Clone issues |
| `jira-as bulk delete` | Delete issues permanently |
