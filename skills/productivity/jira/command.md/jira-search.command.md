# jira-search — Commands

All commands support `--help` for full options.

| Command | Description |
|---------|-------------|
| `jira-as search query` | Execute JQL queries |
| `jira-as search export` | Export results to CSV/JSON |
| `jira-as search validate` | Check JQL syntax |
| `jira-as search build` | Build JQL from clauses |
| `jira-as search bulk-update` | Bulk update issues from search |
| `jira-as search suggest` | Get field value suggestions |
| `jira-as search fields` | List available JQL fields |
| `jira-as search functions` | List available JQL functions |
| `jira-as search filter list` | List saved filters |
| `jira-as search filter create` | Save a reusable filter |
| `jira-as search filter update` | Update an existing filter |
| `jira-as search filter run` | Run a saved filter |
| `jira-as search filter favourite` | Toggle favourite status |
| `jira-as search filter share` | Share filter with users/groups |
| `jira-as search filter delete` | Delete a saved filter |
