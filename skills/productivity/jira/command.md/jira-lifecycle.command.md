# jira-lifecycle — Commands

All commands support `--help` for full options.

### Workflow Transitions

| Command | Description |
|---------|-------------|
| `jira-as lifecycle transitions` | List available transitions |
| `jira-as lifecycle transition` | Move issue to a new status |

### Assignments

| Command | Description |
|---------|-------------|
| `jira-as lifecycle assign` | Assign or unassign an issue |

### Resolution

| Command | Description |
|---------|-------------|
| `jira-as lifecycle resolve` | Resolve an issue |
| `jira-as lifecycle reopen` | Reopen a resolved issue |

### Version Management

| Command | Description |
|---------|-------------|
| `jira-as lifecycle version list` | List project versions |
| `jira-as lifecycle version create` | Create a version |
| `jira-as lifecycle version release` | Release a version |
| `jira-as lifecycle version archive` | Archive a version |

### Component Management

| Command | Description |
|---------|-------------|
| `jira-as lifecycle component list` | List project components |
| `jira-as lifecycle component create` | Create a component |
| `jira-as lifecycle component update` | Update a component |
| `jira-as lifecycle component delete` | Delete a component |
