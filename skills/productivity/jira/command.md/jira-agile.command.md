# jira-agile — Commands

All commands support `--help` for full options.

### Epic Management

| Command | Description |
|---------|-------------|
| `jira-as agile epic create` | Create an epic |
| `jira-as agile epic get` | Get epic details (optionally with children) |
| `jira-as agile epic add-issues` | Link issues to an epic |

### Subtask Management

| Command | Description |
|---------|-------------|
| `jira-as agile subtask` | Create a subtask |

### Sprint Management

| Command | Description |
|---------|-------------|
| `jira-as agile sprint list` | List sprints |
| `jira-as agile sprint get` | Get sprint details |
| `jira-as agile sprint create` | Create a sprint |
| `jira-as agile sprint move-issues` | Move issues to/from a sprint |
| `jira-as agile sprint manage` | Start, close, or update a sprint |

### Backlog Management

| Command | Description |
|---------|-------------|
| `jira-as agile backlog` | View backlog |
| `jira-as agile rank` | Reorder backlog items |

### Story Points and Estimation

| Command | Description |
|---------|-------------|
| `jira-as agile estimate` | Set story points on an issue |
| `jira-as agile estimates` | View estimates by project/sprint/epic |

### Velocity Tracking

| Command | Description |
|---------|-------------|
| `jira-as agile velocity` | Calculate team velocity from completed sprints |
