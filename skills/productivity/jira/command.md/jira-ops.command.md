# jira-ops — Commands

All commands support `--help` for full options.

| Command | Description |
|---------|-------------|
| `jira-as ops discover-project` | Discover project metadata, workflows, and patterns |
| `jira-as ops cache-status` | Display cache statistics |
| `jira-as ops cache-clear` | Clear cache entries |
| `jira-as ops cache-warm` | Pre-warm cache with commonly accessed data |
