# Productivity skills

Paths are relative to `~/.meta-skills/`. Built-in skills under `skills/productivity/`. Use **Folder** as `SRC` for `/meta-skills`;
register under `$DEST/<folder basename>/`. Open the linked `SKILL.md` only for the skill you need.

| Name | Folder | What it does |
|------|--------|--------------|
| `confluence` | [`skills/productivity/confluence/`](../skills/productivity/confluence/SKILL.md) | Confluence via confluence-cli + SkillCred `.env` (read/search/write) |
| `fathom` | [`skills/productivity/video-conf/fathom/`](../skills/productivity/video-conf/fathom/SKILL.md) | Fathom meetings, transcripts, AI summaries, action items |
| `google-workspace` | [`skills/productivity/google/google-workspace/`](../skills/productivity/google/google-workspace/SKILL.md) | Gmail, Calendar, Drive, Docs, Sheets, Contacts, Chat |
| `jira` | [`skills/productivity/jira/`](../skills/productivity/jira/SKILL.md) | Jira Cloud via `jira-as` CLI — router + `command.md/` domains + SkillCred `.env` |
| `pc-report` | [`skills/productivity/pc/pc-report/`](../skills/productivity/pc/pc-report/SKILL.md) | Host monitoring report (Linux / macOS / Windows) |
| `youtrack` | [`skills/productivity/youtrack/`](../skills/productivity/youtrack/SKILL.md) | YouTrack via `yt` (youtrack-cli) — SkillCred `.env` (`URL`, `API_TOKEN`) + `yt auth login` |
