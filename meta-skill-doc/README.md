# meta-skill-doc

Read only the file you need. Paths in these files are relative to `~/.meta-skills/`.

- `<category>.md` — skill catalog for one category (indexed in the root `SKILL.md`).
- `installer/architecture.md` — shared library vs per-workspace credentials, `CURRENT_SKILL_DIRECTORY`.
- `installer/placeholders.md` — TO COPY slice, `{IS_GLOBAL}` / `{TYPE_OF_AI_TOOLS}` / `{SKILL_PATH}`, library reference.
- `installer/register.md` — `install.sh`, resolving `SRC`, registering standard and hub skills, copy map.
- `installer/examples.md` — end-to-end examples per tool.
