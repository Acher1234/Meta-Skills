# Security skills

Paths are relative to `~/.meta-skills/`. Built-in skills under `skills/security/`. Use **Folder** as `SRC` for `/meta-skills`;
register under `$DEST/<folder basename>/`. Open the linked `SKILL.md` only for the skill you need.

| Name | Folder | What it does |
|------|--------|--------------|
| `bitwarden` | [`skills/security/bitwarden/`](../skills/security/bitwarden/SKILL.md) | Bitwarden / Vaultwarden vault via `bw` — items, folders, attachments, Send |
| `folder-crypt` | [`skills/security/folder-crypt/`](../skills/security/folder-crypt/SKILL.md) | Encrypt / decrypt a folder with a password (prompt, args, or SkillCred `.env`) |
| `zscaler` | [`skills/security/zscaler/`](../skills/security/zscaler/SKILL.md) | Zscaler ZPA / ZIA / ZIdentity APIs — SkillCred `.env` with `SECTION__FIELD` keys |
